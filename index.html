Chi-square tests are always right-tailed — the test statistic is a sum of squared deviations, so it can never be negative, and evidence against H₀ only ever shows up as an unusually large value.
Input

F is a ratio of two variances, so it's also bounded below by 0 — ANOVA's F-test is always right-tailed, testing whether between-group variability is unusually large relative to within-group variability.
Input

The studentized range distribution compares the largest gap among k sample means to the within-group variability. Like chi-square and F, it's only ever tested in the right tail. Its critical value takes a numerical integration to compute, so this page may take a moment to update.
Input

Built for classroom use. Critical values and p-values are computed with standard numerical methods (incomplete beta/gamma functions for t, chi-square and F; Gauss–Legendre quadrature over the studentized-range double integral for q), verified against published critical-value tables.
